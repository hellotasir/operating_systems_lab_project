## Operating Systems Lab Project

| Source File | Responsibility |
| :--- | :--- |
| `src/App.jsx` | Controls the current screen and renders the appropriate step of the visualizer. |
| `src/context/SchedulerProvider.jsx` | Stores the shared scheduling state and reducer actions. |
| `src/hooks/useScheduler.jsx` | Provides access to the selected scheduling result and comparison results. |
| `src/utils/Scheduler.jsx` | Contains validation, six scheduling algorithms, Gantt creation, and metric calculation. |
| `src/components/ProcessInput.jsx` | Displays the editable process table. |
| `src/components/AlgorithmSelector.jsx` | Selects the visualization algorithm and comparison algorithms. |
